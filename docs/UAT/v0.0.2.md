## Testing Guide

### LegacyAuth pass
Pick LegacyAuth.
Watch the graph add a legacy node and suspected conflict.
In room 3, confirm the incident becomes a traceable Build Failure.
In the report, check whether it clearly connects the conflict/approval to the outcome.

### Compatibility Shim pass
Pick Compatibility Shim.
Confirm combat feels stronger.
Watch Technical Debt jump.
In room 3, check whether the consequence reads as debt/audit pressure rather than arbitrary punishment.

### Test Suite pass
Pick Test Suite.
Confirm Observability rises and graph info becomes clearer.
Combat should feel slightly worse/slower, but the later consequence should be softer and more explainable.


## Testing Strategy

For each pass, don’t worry about playing optimally. The useful questions are:

- Did the package choice visibly change the graph?
- Did the HUD/log make the change understandable?
- Did room 3 feel connected to the earlier choice?
- Did the final report use facts from the run rather than generic joke text?
- Did combat remain readable while the graph/HUD/log were active?

A single pass only tests one branch, so it’s not enough. Three passes should cover the core slice. After that, one “messy” pass where you intentionally take hits and ignore the graph is useful for checking whether failure still explains itself.

# First Slice Playtest Prompts

Use these after a short run. The goal is not to win; it is to test whether the player can read the choice -> graph mutation -> consequence loop.

## One-Minute Questions

1. Which package did you choose, and what did you think it would do?
2. What changed on the dependency graph after the package installed?
3. Did room 3 feel connected to the package choice? Why or why not?
4. What did the final report say was important about your run?
5. Was any combat damage surprising or hard to read?

## Observer Checklist

- Player noticed the package preview before choosing.
- Player understood at least one graph node or edge added by the package.
- Player used or noticed the enlarged graph view.
- Player could explain one later consequence in their own words.
- Player could distinguish Stability, OBS, and TDR by the end of the run.

## Branches To Exercise

- LegacyAuth: watch for conflict and security-exception story.
- Test Suite: watch for revealed edges and softened staging incident.
- Compatibility Shim: watch for stronger blade damage and TDR/audit pressure.
